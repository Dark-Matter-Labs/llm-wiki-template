# Pre-publication checklist

Confirm each item before publishing. Combines the Publishing Guide (Step 3) and
the AI Usage Guide's pre-publish checks. Items marked (AI) apply only if AI was
used beyond light editing/formatting.

## Attribution & contributors
- [ ] Identified all contributors across text, design, visuals, code, and
      condition-building (best effort + documented decisions where at scale)
- [ ] Shared the proposed credit block with contributors and invited corrections
- [ ] Have consent for any colleague's background IP used
- [ ] External sources and frameworks credited and, where possible, linked
- [ ] A Lineage and intellectual responsibility section is included
- [ ] The correct licence is noted

## Confidentiality & consent
- [ ] Confirmed no confidential partner or client work is being disclosed
- [ ] If participants/partners contributed material, they were informed of any
      AI use and consented (and it was anonymised where relevant)

## Risk & review (from risk_assessment.py / Publishing Step 1)
- [ ] Self-risk assessment complete (irreversibility, exposure, sensitivity)
- [ ] Required review level met (proceed / one peer / structured 1–2 reviewers)
- [ ] If peer review was required, it is done — or the silent-consent deadline
      passed and the request + deadline are documented

## Quality (Style Guide)
- [ ] Primary reader and channel are clear; register matches
- [ ] Complexity check passed (uncertainty kept, disagreement preserved, minority
      views kept, sources not over-generalised, not tidier than reality)
- [ ] Any coined term passes the distortion / justification / anchor tests
- [ ] Positionality handled deliberately; personal-risk / Indigenous-context
      disclosures taken to peer review + consent
- [ ] House conventions consistent (ran mechanical_check.py or checked by hand)

## AI-assisted work (if applicable)
- [ ] (AI) All factual claims, citations, and figures verified against primary
      sources
- [ ] (AI) No confidential, sensitive, or non-consented material was used in
      producing the output
- [ ] (AI) Reviewed by a human for accuracy, complexity, and argument — not just
      polish
- [ ] (AI) AI usage declared in the credit block
- [ ] (AI) If images were AI-generated, this is stated and licensing checked

## Posting
- [ ] Publication date set; named contributors notified
- [ ] Posted intention on #help-publishing (support needs flagged)
- [ ] Channel-appropriate version prepared (see channels.md); status/intended
      reader stated near the top if cross-posting
- [ ] (Medium) Plan to add to the Dm Provocations publication after posting
