# Guides

Short guides for people who use a wiki. Each one answers one question in plain words. Start with
[HOW-IT-WORKS.md](../HOW-IT-WORKS.md) if you are new. These guides go further on one topic each.

| Guide | Read it when |
|---|---|
| [Adding to the wiki](adding-to-the-wiki.md) | You are unsure whether to put something in, or worried it will make a mess. |
| [Your lens](your-lens.md) | You want to read the wiki, share a link to a page, or the password does not work. |
| [Calls and commitments](calls-and-commitments.md) | You want to file a call, or take or close an item from the stand-up. |
| [Asking the wiki](asking-the-wiki.md) | You want to know what to say to Claude, and how to read what comes back. |
| [When something goes wrong](when-something-goes-wrong.md) | A check failed, a page will not open, or Claude says something "clashes". |

These guides are shared by every wiki and are updated for all of them at once. To suggest a change,
say so to Claude in your own wiki, and it is proposed for everyone.
